# 🔐 Java Password Generator with Strength Checker
This is a Java-based Password Generator that creates secure passwords and evaluates their strength. It can generate random passwords based on customizable criteria and provides a basic strength analysis to help ensure the password meets security standards.

## 🚀 Features
- ✅ Random password generation
- ✅ Customize length and character sets (uppercase, lowercase, digits, special characters)
- ✅ Password strength evaluation:
  - Length
  - Use of uppercase/lowercase
  - Use of digits and special characters
  - Avoidance of common weak patterns
- ✅ Console-based user interface
## 🛠️ Technologies Used
- Java (JDK 8 or higher)
- No external libraries required
